 PathlessMark  Version 1.0.0
 この先に道はない。 - サブフォルダを持たないフォルダに、小さな印。
========================================================================

■ このソフトについて

 エクスプローラーで、サブフォルダを含まないフォルダ（＝それ以上掘れない
 フォルダ）にだけ小さな印を付けます。

 開かなくても「ここが行き止まり」と分かるので、深い階層をたどるときの
 無駄な往復が減ります。

 ・動作環境 ： Windows 10 / 11（64bit）
 ・ライセンス： MIT ライセンス（無料・改変再配布自由）
 ・種別    ： フリーソフト（寄付歓迎）


■ ★重要★ 印が出ないことがあります

 Windows は「アイコンの重ね表示（オーバーレイ）」を、システム全体で
 15枠しか持っていません。OneDrive が7枠、Dropbox が3〜4枠…と各社が
 取り合うため、枠が埋まっている環境ではどんなソフトでも印が出ません。

 これは Windows 側の制限で、PathlessMark の不具合ではありません。

 同梱の「PathlessMark 診断」を実行すると、お使いの環境の枠の状況と、
 PathlessMark が有効か無効かがその場で分かります。
 （スタートメニュー → PathlessMark → PathlessMark 診断）

 枠が足りない場合は、使っていない同期ソフトのアイコン表示を減らすと
 空きます。


■ 印の色を変える

 スタートメニュー → PathlessMark → 「PathlessMark 設定（印の色）」

 好きな色を選べます。白いフチの有無も切り替えられます。
 色を変えたら、エクスプローラーを再起動すると反映されます。

 印はフォルダアイコンの左下に小さく出ます（アイコンの4割ほどの大きさ）。
 フォルダの形が隠れないよう、あえて控えめにしてあります。


■ そのほかの注意

 ・コード署名をしていないため、インストール時に
   「WindowsによってPCが保護されました」という警告が表示されます。
   ［詳細情報］→［実行］で進めてください。
 ・反映にはエクスプローラーの再起動が必要です（インストーラが行います）。
 ・判定はローカルの固定ドライブのみです。ネットワークドライブや
   USBメモリは対象外にしています（遅くなる・取り外されるため）。


■ インストール / アンインストール

 インストール ： PathlessMark-1.0.0-setup.exe を実行（管理者権限が必要）
 アンインストール： Windows の「設定」→「アプリ」から

 アンインストールでは、登録を解除してからファイルを削除するので、
 きれいに元の状態へ戻ります。


■ 動作について（速度）

 エクスプローラーはフォルダを表示するたびに「印を付けるか？」を
 拡張機能へ同期的に尋ねます。ここが遅いとエクスプローラー全体が
 重くなるため、次のようにしています。

  1. サブフォルダを1つ見つけた時点で走査を打ち切る（全部数えない）
  2. 結果を30秒キャッシュする
  3. ローカル固定ドライブ以外は即座に対象外として返す

 開発機での実測（200回平均）：
  ・一般的なフォルダ（10項目）        0.086 ミリ秒
  ・大量のファイル（2,341項目）       1.499 ミリ秒（最悪値）
  ・C:\Windows\System32（5,133項目）  0.174 ミリ秒
  ・末端フォルダ（4項目）             0.043 ミリ秒
