# PathlessMark

> **この先に道はない。** — サブフォルダを持たないフォルダに、小さな印。

**サブフォルダを含まないフォルダ（＝それ以上掘れないフォルダ）に、小さな印を付ける**
Windows エクスプローラーの拡張機能です。

開かなくても「ここが行き止まり」と分かるので、深い階層を探すときに往復が減ります。

- 対応：Windows 10 / 11（64bit）
- ライセンス：MIT（無料・改変再配布自由）
- **寄付歓迎**（donationware）— 使って役に立ったら、開発の継続を支えていただけると嬉しいです

---

## 🔴 先に読んでください：印が出ないことがあります

Windows は**アイコンの重ね表示（オーバーレイ）を、システム全体で15枠しか持っていません**。
OneDrive が7枠、Dropbox が3〜4枠…と各社が取り合うため、**枠が埋まっている PC では
どんなソフトでも印が出ません**。これは Windows 側の制限で、PathlessMark の不具合ではありません。

**同梱の「PathlessMark 診断」を実行すると、あなたの PC の枠の状況と、
PathlessMark が有効か無効かがその場で分かります。**
（スタートメニュー →「PathlessMark」→「PathlessMark 診断」）

枠が足りない場合は、使っていない同期ソフトのアイコン表示を減らすと空きます。

> ℹ️ PathlessMark は登録名を `"  PathlessMark"`（先頭にスペース2個）としています。
> Windows は登録名の**辞書順**で先頭15件を採用するため、多くのソフトが先頭にスペースを
> 入れて順番を確保しています。PathlessMark も同じ方法で枠を取りに行きます。
> 隠さずに書いておきます。

## その他の注意

- **コード署名をしていません。** インストール時に「WindowsによってPCが保護されました」
  という警告が出ます（[詳細情報]→[実行]で進めます）。証明書の費用を寄付でまかなえる
  規模になったら導入したいと考えています。
- 反映には**エクスプローラーの再起動**が必要です（インストーラが行います）。
- 判定するのは**ローカルの固定ドライブのみ**です。ネットワークドライブや USB メモリは
  対象外にしています（遅くなる・外れることがあるため）。

## 仕組み（速度について）

エクスプローラーはフォルダを表示するたびに「このフォルダに印を付けるか？」を
拡張機能へ**同期的に**尋ねます。ここが遅いとエクスプローラー全体が重くなります。
PathlessMark は次のようにしています。

1. **サブフォルダを1つ見つけた瞬間に走査を打ち切る**（全部数えない）
2. 結果を**30秒キャッシュ**する（同じフォルダを何度も聞かれるため）
3. ローカル固定ドライブ以外は**即座に対象外**として返す

実測（この開発機・200回平均）：

| 対象 | 項目数 | 判定 | 所要 |
|---|---|---|---|
| 一般的なフォルダ | 10 | あり | 0.086 ms |
| 大量のファイル | 2,341 | あり | **1.499 ms**（最悪値） |
| `C:\Windows\System32` | 5,133 | あり | 0.174 ms |
| 末端フォルダ | 4 | **なし** | 0.043 ms |

## インストール

1. [Releases](https://github.com/nanana03/pathlessmark/releases) から `PathlessMark-x.y.z-setup.exe` を入手
2. 実行（管理者権限が必要です）
3. 最後に「エクスプローラーを再起動して今すぐ反映する」にチェックを入れて完了

アンインストールは「アプリと機能」から。登録を解除してから DLL を削除するので、
きれいに元へ戻ります。

## 開発者向け

```powershell
# ビルド（要：VS の「C++ によるデスクトップ開発」ワークロード）
powershell -ExecutionPolicy Bypass -File build.ps1

# 登録（管理者）／解除
powershell -ExecutionPolicy Bypass -File register.ps1
powershell -ExecutionPolicy Bypass -File unregister.ps1

# インストーラ作成（要 Inno Setup 6）
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\PathlessMark.iss
```

### 踏んだ罠（同じところで詰まらないために）

- 🔴 **cl には `/utf-8` が必須**。無いと MSVC がソースを CP932 と解釈し、日本語コメントの
  途中バイトが行継続扱いになって**次の行を飲み込む**（`C2059 syntax error: 'return'` が多発）
- 🔴 **日本語入りの `.ps1` は UTF-8 BOM 必須**。無いと PowerShell 5.1 が SJIS と解釈して
  構文が壊れる（`}` が余分に見える）
- 🔴 **PowerShell の文字列連結の途中に `#` コメントを書かない**。行の残りが全部コメントに
  なり、`cl` の行が丸ごと消えたまま「成功」と表示された
- 🔴 **登録中は DLL を上書きできない**（Explorer が掴んでいる）。再ビルドの前に
  `unregister.ps1` → エクスプローラー再起動
